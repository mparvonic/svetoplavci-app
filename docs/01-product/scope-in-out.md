# Scope (in/out)

## In-scope (nejbližší fáze)

- M01 Výsledky vzdělávání (lodičky, hodnocení, vysvědčení, archivace podkladů).
- M12 Platform core (auth, role-based přístup, konfigurace, audit, notifikace, API foundation).
- Přechod z Coda na vlastní databázový model.
- Základní provozní a status dokumentace.

## In-scope (navazující fáze)

- M02 Organizace školního roku.
- M03 Ostrovy.
- M04 Půjčovna a rezervace zdrojů.
- M05 Studijní portfolio.
- M07 Kiosk.

## Out-of-scope (zatím)

- Plně automatizovaný převod historických hodnocení mezi verzemi RVP/lodiček.
- Plně konverzační AI ovládání celé aplikace bez GUI fallbacku.
- Integrace síťového managementu v plném rozsahu (zůstává ve fázi návrhu a pilotu).
