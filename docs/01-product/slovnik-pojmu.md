# Slovník pojmů

- `RVP`: Rámcový vzdělávací program pro základní vzdělávání.
- `OVU`: očekávaný výstup učení definovaný v RVP.
- `lodička`: interní vzdělávací výstup školy Světoplavci.
- `stupeň lodičky`: nezahájeno / rozpracováno / s dopomocí / částečně / samostatně.
- `plavba`: dílčí vzdělávací cyklus v rámci školního roku.
- `triangl`: společné hodnocení dítěte, průvodce a rodiče.
- `školní rok`: konfigurovatelné období s 5 plavbami.
- `smečka`: školní třída / organizační skupina.
- `posádka`: studijní skupina.
- `ostrov`: tematický kurz, na který se dítě hlásí.
- `kioskový režim`: veřejný režim na školních tabletech pro rychlé provozní úkony.

## Terminologické pravidlo

V projektové dokumentaci zachováváme tyto pojmy beze změn a nepřekládáme je do obecné angličtiny.
