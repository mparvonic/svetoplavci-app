# Monitoring a alerting

## Monitorovat minimálně

- dostupnost aplikace,
- latenci klíčových endpointů,
- chybovost API,
- stav integračních jobů,
- stav DB (connections, storage, long queries).

## Alerting

- kritické alerty: okamžité notifikace,
- varovné alerty: agregované notifikace,
- každá kritická notifikace musí mít runbook odkaz.
