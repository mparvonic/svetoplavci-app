# Test strategie

## Cíle

- Ověřit funkčnost kritických toků školy.
- Ověřit bezpečnost role-based přístupů.
- Ověřit stabilitu výpočtů hodnocení.

## Test pyramid

- Unit testy: výpočty, mapování, validace.
- Integrační testy: API + DB + policy.
- E2E testy: klíčové uživatelské scénáře.

## Prioritní oblasti

- M01: výpočty pokroku a snapshoty vysvědčení.
- M12: autorizace a audit.
- M06/M10: správné zobrazení obsahu podle role.
