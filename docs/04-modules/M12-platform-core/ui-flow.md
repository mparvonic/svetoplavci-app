# M12 UI flow

## Správce aplikace: role a oprávnění

1. Otevře správu uživatelů.
2. U vybraného uživatele nastaví role.
3. Systém zobrazí dopad oprávnění.
4. Po potvrzení vznikne auditní záznam.

## Správce aplikace: konfigurace

1. Otevře systémovou konfiguraci.
2. Upraví nastavení.
3. Systém vyžádá potvrzení.
4. Změna se uloží jako nová verze konfigurace.
