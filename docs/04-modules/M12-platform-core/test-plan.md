# M12 Test plán

## Unit testy

- Vyhodnocení policy pravidel.
- Validace role assignmentu.

## Integrační testy

- Přidání/odebrání role uživateli.
- Vynucení autorizace v chráněných API.
- Audit event při změně konfigurace.

## E2E testy

- Uživatel s rolí průvodce má přístup jen k oprávněným sekcím.
- Uživatel bez role nemá přístup k administraci.
