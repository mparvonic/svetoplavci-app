# M12 Platform core

## Účel modulu

Poskytovat společné aplikační služby pro všechny moduly: autentizaci, autorizaci, audit, konfiguraci, notifikace, API standard a provozní foundation.

## Scope

- In-scope:
  - identity a role,
  - policy engine pro oprávnění,
  - audit log,
  - konfigurace školního prostředí,
  - API standardizace,
  - observabilita a provozní baseline.
- Out-of-scope:
  - doménové workflow konkrétních modulů (M01+).
