# M12 Požadavky

## Funkční požadavky

1. Systém musí podporovat více rolí a dílčích rolí.
2. Systém musí mít policy vrstvu pro autorizaci operací.
3. Systém musí auditovat kritické změny.
4. Systém musí mít centrální konfiguraci prostředí (školní rok, feature flags, integrační klíče).
5. Systém musí poskytovat jednotný API standard (chyby, paging, verze).

## Ne-funkční požadavky

- Bezpečnostní baseline pro autentizaci a session.
- Diagnostika incidentů (logy, metriky, korelace requestů).
- Připravenost na modulární růst aplikace.
