# M01 Test plán

## Unit testy

- Mapování stupňů lodiček na body.
- Agregační funkce lodička -> oblast -> předmět.
- Determinismus výpočtu pokroku.

## Integrační testy

- Zápis progress eventu a následné načtení historie.
- Generování podkladů trianglu pro plavbu.
- Generování snapshotu vysvědčení.

## E2E testy

- Průvodce upraví lodičku a rodič vidí změnu.
- Uzavření vysvědčení vytvoří neměnný snapshot.

## Bezpečnostní testy

- Rodič nesmí číst cizí dítě.
- Uživatel bez role průvodce nesmí měnit progress.
