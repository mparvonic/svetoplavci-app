# Model hodnocení

## Stupnice lodičky

- `0` nezahájeno
- `1` rozpracováno
- `2` s dopomocí
- `3` částečně
- `4` samostatně

## Výpočet pokroku

- Každá lodička má bodovou hodnotu odvozenou ze stupně plnění.
- Očekávaný pokrok je definován křivkou po pololetích/plavbách.
- Porovnání `skutečnost vs. očekávání` se vyhodnocuje po úrovních:
  - lodička,
  - oblast,
  - předmět,
  - souhrn dítěte.

## Výstupy

- podklady pro triangl,
- podklady pro vysvědčení,
- rodičovský náhled pokroku,
- interní analytika průvodce.

## Otevřené body

- Přesná definice vážení mezi oblastmi/předměty.
- Přesná pravidla převodu při `AUTO_1_N` a složitějších migracích.
