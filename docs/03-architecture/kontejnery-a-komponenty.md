# Kontejnery a komponenty

## Aplikační kontejnery

- `Web App` (Next.js): UI + API vrstvy.
- `PostgreSQL`: transakční data, konfigurace, audit, snapshoty.
- `Background jobs`: synchronizace/importy/integrace.
- `Object storage` (navazující fáze): soubory portfolia.

## Komponenty aplikace

- Auth a IAM vrstva.
- Modul hodnocení a lodiček.
- Modul školní rok/plavby.
- Modul ostrovy.
- Modul půjčovna a rezervace.
- Modul portfolio.
- Integrace vrstva (Edookit, Google, RVP).
- AI orchestrace (pozdější fáze).
