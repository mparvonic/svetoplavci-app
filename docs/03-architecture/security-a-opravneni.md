# Security a oprávnění

## Autentizace

- Podpora více providerů.
- Povinné zabezpečení session a tokenů.

## Autorizace

- Role-based + kontextová pravidla (dítě, skupina, školní rok).
- Jemnozrnná oprávnění pro čtení, zápis, schválení, administraci.

## Audit

- Auditní záznam pro změny hodnocení, oprávnění, konfigurací a importů.
- Dohledatelnost změn pro interní i legislativní potřeby.

## Ochrana dat

- Minimalizace přístupu k citlivým údajům.
- Definovaná retence a archivace.
- Obnova po havárii (viz `07-operations/backup-and-restore.md`).
